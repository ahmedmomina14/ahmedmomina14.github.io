My strongest projects which I built in class are the "Hidden Figures" and "Creating Your Own Animations." In my animation project, I used basic CSS and HTML to create a spinning sun, moving car, and a floating balloon which helped me improve my creativity skills.

The projects and classwork I completed in this course inspired me to continue learning about technology.
